If you like math, then you certainly know about prime numbers

We'll assume you detest math, just for the sake of inclusivity, and actually this doesn't mean you need to be a math geek, to code, but this lesson is about a mathematical concept, so math surely will help.

And anyway you better learn math because there will be a lot more of these later on.

Anyway, so as you probably know, prime numbers have only wo factors, the number and 1

For example, 5 is prime because it can only be factorised to 5 and 1, whereas 4 can be factorised to 1 * 4, and also 2 * 2.

Now, the first thing that should come to your mind, is that that means even numbers are all unprime (or composite to be accurately speaking), and any prime should be odd. That's right, if we ignore 2, but yes, 2 is the only even prime.

Now, if we work our way through, we'll find it is the same for every single other number.

For example, any number divisible by 3 is composite except for 3 itself, and so on.

Also, number 1 technically isn't prime, because it only has 1 factor, not two.

Prime numbers are actually really useful in our daily lives, so we'll explore them a little before jumping to the code.

Just remember that the code in this lesson, is not actually the most efficient way, but it is used for demonstration.

Now, our coding task will be counting the number of prime numbers in a range of 1 to any user input integer

Code

First of all the code for the user input.

int x;
cin << x;

Now, the user inputs a number and is stored in x, as an integer.

Now the logic behind the following code will be using a simple approach, which is to check if x can be divided by any of the number smallers than it. If yes, it is composite, if no, it is prime.

bool prime = true;
for (int i = 0; i < x; i++){
    if (x % i == 0) {
        prime = false;
        break;
    }
}
cout << prime ? "Prime" : "Composite"; // You can ignore this line, it just outputs prime if it prime == true, and composite if prime == false. It's called a ternary operator by the way.

Now, that would certainly work just fine for small numbers, because it will only need a limited number of checks to do, and will occasionally finish early, because of the break (it stops the loop, when the condition is met), but this is unnecessarily slow.

Code v2

Now one area of improvement would be in the loop itself. It checks for x times, but as we know, factors have to be either equal (as in 2 * 2, or 3 * 3) or, one WILL be greater than the other (like 5 * 3 for instance). Now, how do we tell where the numbers will simply be repeating?

The answer lies in the square root of x. The square root is the number that when multiplied by itself, will result in x. For example for 4 it is 2, for 9 it is 3 and so on. Now, mathematically, that has to be the point where any number will be from the bigger numbers, and those aren't worth checking, because we have already checked their pairs, the smaller numbers.

The thing is though, using the square root can be quite a hassle in C++, since it takes time, so a faster way would be to do the opposite

i * i <= x. If you think it through, you will notice that i will never pass the square root.

bool prime = true;
for (int i = 2; i * i <= x; i++){
    if (x % i == 0) {
        prime = false;
        break;
    }
}
cout << prime ? "Prime" : "Composite"; // You can ignore this line, it just outputs prime if it prime == true, and composite if prime == false. It's called a ternary operator by the way.

Using the exact same code, with just that change, makes a HUGE time difference, but we can still improve more.

Functions

Just in case you haven't noticed we still haven't got to our target. Our code only tells if a number is prime or not, but doesn't actually count.

This is why we have to use functions. We don't really have to, but it will make the code way more readable. Functions are pretty much anything you see with two parantheses after it. Some are builtin, and others can be userdefined, but they are the same idea. You have all this code, that you want to reuse, so you make a function and call it, instead of copying and pasting all this code.

For our task, we have to make a function with our previous code to check if a number is prime, then return if it is.

Let's try it out:

bool prime(int x){
    bool prime = true;
    for (int i = 2; i * i <= x; i++){
        if (x % i == 0) {
            prime = false;
            break;
        }
    }
    return prime;
}

Don't worry the code we added is really simple. The first line is function declaration (we have to add the return type in this case a boolean, but it is often void, which returns nothing), and since we have to have input, we added an arguement (int x). In the end, we added a line (return prime) to return the result after finding it.

For Loop

Now, we just want to put it in a loop. Previously, we used a while loop, but here a for loop would be more suitable. Btw, a for loop COULD be used as a while loop, and vice versa, but it simply isn't ideal. Like you could do a while loop that adds an iterator, instead of for, but WHY!? You could also add a condition to a for loop, instead of adding every time, but it's simply ridiculous (*>﹏<*)

We also used a for loop in the previous function but since it wasn't explained, this is the perfect opportunity to explain it.

Declaring a for loop needs 3 things. First, we declare the iterator (usually called i but you could call it breakingBad if you want). Secondly, we need a condition, for example i < 8. The loop will work as long is i < 8. Finally, we add the increment line (not necessarily increment as we will see). This is typically i++, but if you really want, you could just go i-- or i+=5 etc.

Here is the syntax for a for loop.

for (int i = 0; i < maxNumber; i++) {whatever will be looped}

One thing to remember is that i here will start at 0 at end at (maxNumber - 1). If maxNumber is 5, and i = 5, then the condition would be false, and it will stop iterating.

What if you need a normal counter though? Well there are 2 ways

- Either you just call i + 1 instead of i

- OR you could play it smart, and go (int i = 1; i <= maxNumber; i++)

You choose for yourself though.

Final Code

Now, let's put everything together.

First we need our function, then in the main code, we will take input, and loop based on it. Finally we output the number of prime numbers.

#include <iostream>
using namespace std;

bool prime(int x){
    bool prime = true;
    for (int i = 2; i * i <= x; i++){
        if (x % i == 0) {
            prime = false;
            break;
        }
    }
    return prime;
}

int main(){
    cout << "Enter your number" << endl;
    int x; cin >> x;
    int primeNo = 0; 
    for (int i = 2; i < x; i++){
        if (prime(i)) {primeNo++;}
    }
    cout << "There are " << primeNo << " prime numbers between 0 and " << x << " (not including x)";
}

The things we added here different are mainly aesthetics, like endl, which adds a new line. As for the first two lines they are for the code to run, as we explained before
