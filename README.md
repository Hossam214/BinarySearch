Honestly this project is pretty much self-explanatory, but still let me tell you what it is about. 

I made this website, because I recently got into a C++ course about Competitive Programming fundamentals, so I decided to take this as an oppurtunity to make sure I really learned what was in the course, and didn't just skim it. So, I decided to explain it in a website, each concept alone. 

Also, while I was in the course, many concepts felt too advanced in the beginning, which made me want to make sure I can make my explanation as easy and logical as possible. Obviously though, it is pretty hard to find out whether or not somebody who has never heard about these concepts, will manage to easily grasp them, with this website, but it's an attempt, and if you feel anything needs clarification, just send a message on GitHub, and I'll do my best.

Even if, it just needed you to read it a few times, and then you got it. I want this as easy as possible for ANYONE.
